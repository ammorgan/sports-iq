# Sports IQ Mobile

Expo/React Native companion app for iOS, Android, phones, and tablets. It shares the web app's sports and quiz data from `../app/learning-data.ts`, so rules corrections stay aligned across platforms.

## Run

```bash
pnpm install
pnpm start
```

Then press `i` for iOS Simulator, `a` for an Android emulator, or scan the development-build QR code on a supported device.

SDK 57 targets iOS 16.4+ and Android 7+.
